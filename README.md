# Tolti

Tolti is a local-first collaborative workspace for AI-assisted writing, coding, and research.

## Structure

- `frontend/` - React + TypeScript + Vite
- `backend/` - FastAPI + SQLAlchemy
- `infra/modal/` - Modal model deployments
- `docs/` - Product and architecture docs
- `scripts/` - Dev helpers
- `data/` - Runtime SQLite and uploads
